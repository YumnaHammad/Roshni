# Roshni

Online store for Roshni unstitched fabrics. Built with Next.js (App Router). Orders are sent over WhatsApp and paid Cash on Delivery. There is no backend or database.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
npm run lint
```

## Environment setup

Copy the example file and fill it in:

```bash
cp .env.example .env.local
```

| Variable | Example | Used for |
| --- | --- | --- |
| `NEXT_PUBLIC_WHATSAPP_NUMBER` | `923001234567` | Where orders and chats are sent |
| `NEXT_PUBLIC_SITE_URL` | `https://roshni.pk` | Canonical links, Open Graph, Product JSON-LD |

Both values are read at **build time**, so rebuild (or restart `npm run dev`) after changing them.

## Changing the WhatsApp number

Set `NEXT_PUBLIC_WHATSAPP_NUMBER` in `.env.local`, or in your host's environment settings when you deploy. Use the international format with digits only: `92` + the number without its leading `0`. For example, `0300 1234567` becomes `923001234567`. Then rebuild.

## Adding a product

All products live in `lib/data.ts`. That file is the only place product data is stored.

1. Add photos to `public/products/`. Use a 4:5 portrait ratio, around 1200×1500. The **first** image is the main photo. The **second** is shown when a shopper hovers over the card.
2. Add an entry to the `seeds` array:

```ts
{
  slug: "noor-lawn",                       // URL: /product/noor-lawn (must be unique)
  name: "Noor Lawn",
  collection: "summer-lawn",               // a slug from `collections`
  fabric: "Lawn",                          // one of the Fabric types
  pieces: "3 Piece",                       // "3 Piece" | "2 Piece" | "Shirt"
  color: { name: "Rose", hex: "#d9798a" }, // shown as a swatch dot
  base: 4200,                              // price for 2.5m; 3m and 4m are derived
  discount: 20,                            // optional, % off. The product then appears in Sale
  tags: ["new"],                           // optional: "new" and/or "bestseller"
  description: "…",
  includes: ["Printed lawn shirt 3m", "Chiffon dupatta 2.5m", "Cambric trouser 2.5m"],
  care: ["Hand wash cold", "Dry in shade"],
  inStock: true,
  addedAt: "2026-10-07",                   // used for "Newest" sorting
},
```

   Images default to `/products/<slug>-1.svg`, `-2.svg` and `-3.svg`. To use your own photos, either save them under those names or change the `images` helper in `data.ts`.

3. Run `npm run build`. Everything else picks up the new product automatically:
   - product page and Open Graph image
   - JSON-LD
   - search, filters and the mega menu
   - New In / Best Sellers / Sale tabs and related products

**Collections:** add to `collections` in the same file, with a banner image. `new-arrivals` and `sale` are virtual collections, filled automatically from `tags` and `discount`.

**Placeholder art:** the current images and banners are generated by `node scripts/make-art.mts`. Rerun it after adding products if you don't have photos yet. Replace the files with real photography before launch.

## Adding a payment gateway later

Every order goes through `placeOrder()` in `lib/checkout.ts`. To add a gateway:

1. Add a new value to the `payment` enum and to `paymentLabels`.
2. Add a branch in `placeOrder()` that creates the payment session and returns its `redirectUrl`.

The form, cart and success page do not need changes.
